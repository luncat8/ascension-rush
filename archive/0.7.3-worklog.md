# 0.7.3 — Build the rocket that fits

## Shipped

- Oversized contract opportunities without an existing fitting fleet type now
  include a **Build the rocket that fits** action. It keeps the contract loaded
  and opens the workshop at its origin with a new draft based on the current
  strongest type (or the world's reference build), scaling fuel until the
  evaluated payload limit clears the contract with a small margin.
- The suggested design is a new type, not an edit of its source type. Saving
  it selects the new type for dispatch; the player can then build it at the
  origin with the workshop's normal cost and validation.
- If the best scaled design still cannot carry the cargo, the row retains its
  existing generic workshop cue and does not offer a misleading suggestion.
- The opportunity row is now a non-button role-button container so its nested
  build action is valid interactive markup and keyboard-activatable.

## Validation

- JavaScript syntax checked on the changed modules; `git diff --check` clean.
- Per instruction, old test suites were not run. No browser visual check was
  performed.

## Next step

Fly a large contract through the new flow in a browser: confirm the workshop
opens with a viable draft, its quoted cost and payload limit make sense, and
saving/building the new type leaves the original type unchanged. Then revisit
the suggestion sizing if the scaled design feels oversized or underpowered.
