# Worklog — 0.3.1 Aerodynamic envelope and measurements

## Plan review
- Kept this slice limited to the new aerodynamic model, telemetry and
  measurements. No autopilot envelope limits or profiles were tuned; that work
  belongs to 0.3.2 and should use the measured post-aero data.
- Expanded the measurement brief to record AoA both at peak Q and at the peak
  AoA sample with its concurrent Q. Independent maxima alone hide whether a
  high AoA occurred under meaningful aerodynamic load. Airless-world AoA is
  reported as not applicable in route summaries and debriefs.
- The former envelope script only flew from the home pad. It now covers all
  twelve directed routes per planet, so departure pad and wrap direction are
  represented before limits are selected.

## Implemented
- Added `js/aerodynamics.js`: allocation-free dynamic pressure, symmetric
  prograde / retrograde angle of attack, angle-dependent drag coefficient and
  drag acceleration. The axial coefficient remains 0.22 and reference area
  remains 1.6 m²; `CdAlpha = 0.5` adds broadside drag without changing axial
  calibration.
- `physics.step` now uses that helper and records current / peak Q, altitude
  and AoA at peak Q, peak atmospheric AoA with concurrent Q, and peak
  available thrust acceleration (`T / mass`). Measurements are scalar fields
  on the existing flight record; the aero output uses a reused scratch record.
- Added current Q, AoA and peak Q to the flight HUD. The debrief preserves the
  pressure / AoA context and thrust-acceleration peak as data and readable
  report text; these values do not cause damage.
- Extended `experiments/envelope.js` across every directed pad pair and added
  `experiments/aerodynamics-test.js` for formula, vacuum, zero-speed, alignment
  and drag-direction checks.
- Updated script order, regression suites, the 0.3.x plan and README commands.
  Refreshed `0.4-plan.md`'s route-time / fuel baseline so later economy tuning
  uses the post-aero reference flights, with peak Q and AoA at peak Q included.

## Measurements before autopilot-limit tuning
All values below use each planet's reference rocket over all 12 directed
routes. Q maxima and time / AoA values are rounded; angle at peak Q is shown
separately from the absolute peak AoA.

| World | Routes delivered | Peak Q (AoA at peak Q) | Absolute peak AoA (Q at that sample) | Peak T/m | Home short / long hop |
|---|---:|---:|---:|---:|---:|
| Verdant | 12/12 | 32.2 kPa (27.7°) | 90.0° (16.4 kPa) | 25.1 m/s² | 44.6 / 62.5 s |
| Tinmoon | 10/12 | 0 kPa (n/a) | n/a | 19.4 m/s² | 46.6 / 82.8 s |
| Cinder | 12/12 | 79.6 kPa (36.1°) | 90.0° (0.4 kPa) | 35.0 m/s² | 47.6 / 68.0 s |
| Gossamer | 12/12 | 66.2 kPa (9.2°) | 90.0° (2.2 kPa) | 24.7 m/s² | 52.9 / 94.6 s |

Tinmoon's two crashes are the same directed routes that already failed in the
0.3.0 baseline, rather than new aerodynamic regressions. The 0.3.0 atmospheric
peak-Q maxima across the same route sweep were 32.9 kPa (Verdant), 82.2 kPa
(Cinder) and 69.3 kPa (Gossamer); the AoA drag term reduces those peaks by a
few percent while preserving short-hop pacing. The absolute 90° AoA peaks on
Cinder and Gossamer occur at low Q, while their angles at peak Q are 36.1° and
9.2° respectively. That distinction is important when setting the later Q-fade
and AoA limits.
