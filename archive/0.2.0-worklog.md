## Implemented
- Added first-pass rocket constants, mass/thrust/Isp calculations, a one-to-three-stage builder, strength/fuel/payload controls, TWR and staged dV estimates, and launch affordability checks.
- Added fixed-120-Hz semi-implicit physics with inverse-square gravity, exponential atmosphere, quadratic drag, clamped fuel flow, unbounded wrap-X longitude, and interpolated touchdown detection.
- Added mouse-directed thrust-vector control, bounded heading slew, held Shift/Ctrl throttle, Space staging, live telemetry, target range, and a throttle flame.
- Added pad-to-pad launch/landing/crash outcomes and flight-aggregated cash accounting: hull cost at launch, fuel as consumed, and delivery reward only for safe target-pad touchdown. Safe landings return to the builder at the landing pad; crashes return to the departure pad.
- Updated the README and agent findings, and added headless physics, builder flow, and app smoke regression coverage.
